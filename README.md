A tiny Node 22 program for the make.fun bounty
[The Perfect Pickup Line](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6).

`main.ts` writes one pickup line to `/output/entry.txt`:

> I ran a million simulations of meeting you, and every single one ended with me saying hi.

A million simulations, and the optimal move is still just "hi" — machine
voice, a twist, flattering, and no pressure. No network, no randomness, no
input — the same line on every run.

## Run it

```sh
node main.ts
```
